# QR3D Studio (qr3dstudio.online)

Generador client-side de códigos QR para impresión 3D en formato **.3MF multicolor** y **.STL**.

## Características
- **100% Client-Side:** Sin servidores externos ni base de datos.
- **Multicolor:** Soporte nativo para Bambu Lab AMS y Prusa MMU.
- **Ajuste de texto:** Soporte de 2 líneas con auto-escalado dinámico.
- **PWA & Offline:** Funcionamiento sin conexión mediante Service Worker.

## Despliegue en GitHub Pages
1. Sube todos los archivos a la rama `main`.
2. En GitHub ve a **Settings > Pages**.
3. Selecciona la rama `main` y guarda.
